### Herramienta: ENTREVISTA_LIBRE

- **Descripción**: Úsala cuando la idea no depende de este repositorio, o cuando `entrevista-con-repo` ya dejó decisiones que el repositorio no responde. En ese caso va después. No la uses para crear la issue, la rama ni la pull request. No tiene script ni MCP.
- **Inspiración**: [grill-me](https://www.skills.sh/mattpocock/skills/grill-me), de Matt Pocock. Esta versión pregunta una cosa cada vez. No hace falta instalar la original.

#### Cómo entrevistar

1. Haz una pregunta cada vez. Espera la respuesta antes de la siguiente.
2. En cada pregunta, ofrece una respuesta recomendada.
3. No abras el código para contestar. Esta skill no recorre el repositorio.
4. Devuelve qué hay que hacer y cómo se comprueba. El resumen único lo cierra `help-me-to-think`.
