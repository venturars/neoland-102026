# AGENTS.md — bootcamp-102026

## Proyecto

Este repositorio es el del bootcamp. Lo usan alumnos junior y personas que no programan. Piden el trabajo con sus palabras. El agente reconoce a qué momento se refieren.

`README.md` es el documento principal. Léelo antes de instalar o de dar por hecho que una skill o un MCP está disponible.

## Skills y MCPs

Las skills de este flujo están en `SKILL.md`

Dentro de cada skill, la sección «Convención de este repositorio» me pregunta cuando choca con el texto de origen.

Los servidores MCP están en `MCP.md`

## Cómo entiende al alumno

El alumno cuenta qué quiere: dejar una tarea escrita, empezar a hacerla, guardar lo que acaba de hacer, que unos compañeros la miren, o pasarla a `staging`.

El agente traduce eso a un momento del camino. Si la petición cabe en dos momentos, pregunta cuál es y espera. Puede pedir un momento o el camino entero. Antes de cada momento enseña los datos y espera el sí.

## Qué va primero

El camino de git está en `docs/GIT-WORKFLOW.md`. Va antes que el `AGENTS.md` de una app.

Si el alumno explica una funcionalidad («quiero agregar…», «va a ser…»), aunque nombre una app, el momento es dejar la tarea escrita. El agente enseña la issue y espera el sí. En ese momento no escribe la spec de la app.

El `AGENTS.md` de la app dice cómo se construye esa app. Se usa cuando el momento ya es hacer el cambio en la rama. No sustituye la issue, la rama ni la pull request.
