# Tareas — referencia del MCP de Socket

1. Abrir `MCPS/socket-mcp/mcp.txt`.
   La línea es la del plan.
   Es la misma forma que `MCPS/github-mcp-server/mcp.txt`.

2. Abrir `docs/ARCHITECTURE.md`.
   Añadir la línea del MCP de Socket después de la de GitHub.
   El texto es el de la arquitectura en el plan.

3. Abrir `docs/CONSTITUTIONS.md`.
   En `## Paquetes`, después de la frase que valida con Socket, añadir el texto del plan.
   `AGENTS.md` no lleva ese texto.

4. Comprobar los tres textos.
   `mcp.txt` es la dirección del servidor remoto.
   `docs/CONSTITUTIONS.md` nombra `depscore`, `alerts` y `threat_feed`, y el motivo si una herramienta no contesta.
   `docs/TREE.md`, `package.json` y el código no cambian.
