# Tareas — orden del desarrollo

1. Abre `AGENTS.md`, sección «Orden».
   Un cambio del proyecto es un desarrollo: función, dependencia, configuración o documentación.
   El primer proceso escribe la spec y se para. La implementación empieza cuando una persona lo pide.
   Esa sección se lee en el documento.

2. Abre `AGENTS.md`, sección «Reglas».
   Las dos primeras reglas repiten ese orden.
   La tercera dice que, si no hay spec para ese cambio, se crea y se para.
   Esas reglas se leen en la sección.

3. Abre `docs/specs/orden/`.
   Están `spec.md`, `plan.md` y `tasks.md`.
   `AGENTS.md` no se vuelve a editar.
   El texto de «Orden» y de «Reglas» sigue igual.
