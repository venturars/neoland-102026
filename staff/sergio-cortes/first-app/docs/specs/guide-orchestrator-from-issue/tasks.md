# Tareas — guiar de la issue a Empezar

1. Abrir `exercises/git-workflow-agent-template/agents/git-workflow-agent.md`,
   Validación. Tras los bullets de crear la issue, añadir: si la issue
   ya está escrita y el trabajo siguiente hace cambios, el momento
   es Empezar.

2. En Dejarla escrita, tras `agents/create-issue.md`, añadir: si a
   continuación se van a hacer cambios, el momento siguiente es
   Empezar.

3. Comprobar. No hay «no se cierra el turno» ni «no escribe hasta
   tener la URL». No reaparece `## 0. Al integrarlo en un proyecto`.
   `AGENTS.md`, skills, tools y el orquestador de first-app no cambian.
