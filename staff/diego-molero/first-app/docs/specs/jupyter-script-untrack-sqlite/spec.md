# Script de Jupyter y archivos locales

Jupyter se abre mediante el script de la aplicación. La base de usuarios, el entorno de Python y los archivos temporales de notebooks permanecen en local.

La aplicación conserva la base que ya existe. Al obtener el proyecto no se reciben usuarios ni resultados de ejecuciones anteriores. Quedan fuera borrar datos personales y mantener lanzadores alternativos.
