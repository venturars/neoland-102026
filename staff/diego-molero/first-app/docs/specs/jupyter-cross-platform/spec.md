# Arranque de Jupyter en Windows y Linux

La persona abre los nueve documentos desde first-app. El primer arranque prepara un entorno local de Jupyter Notebook; los siguientes reutilizan ese entorno.

En Windows y Linux la salida admite nombres y tablas UTF-8. La ausencia de Python 3 o un fallo de preparación o arranque se comunica con estado de error. El entorno pertenece a esta aplicación y no utiliza el Jupyter global.

La compatibilidad de cada sistema se registra solo cuando se haya probado en ese sistema.
