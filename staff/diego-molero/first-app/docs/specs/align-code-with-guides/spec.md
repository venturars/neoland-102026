# Alinear el código con las guías

Quien lee first-app sigue las validaciones y operaciones en pasos pequeños. Las operaciones actuales conservan sus firmas, reglas, mensajes, datos y orden de validación.

No se modifica el esquema, la normalización del correo, la actualización parcial ni el funcionamiento del clasificador. La búsqueda por nombre es una funcionalidad nueva independiente de esta reorganización.
