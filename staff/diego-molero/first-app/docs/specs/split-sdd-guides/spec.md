# Separar las guías del proyecto

Quien mantiene first-app encuentra cada regla en su guía: arquitectura, árbol, datos, errores o estilo. La constitución reúne las reglas generales y los comandos de ejecución.

Los enlaces permiten llegar a las specs de usuarios, clasificador y Jupyter. El contenido describe el comportamiento actual: reorganizarlo no modifica fechas, validaciones ni resultados.
