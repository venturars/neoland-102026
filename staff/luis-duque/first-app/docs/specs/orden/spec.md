# Un solo gestor de paquetes

Este resultado ya está en el proyecto. Este documento lo deja escrito.

Las dependencias quedan instaladas con un solo gestor: pnpm, versión 12.15.0. Es la versión que ya dejó instalado lo que hay ahora.

La dependencia que ya está se queda en su versión: openai 7.39.0.

Quien instale el proyecto, o añada una dependencia, usa ese gestor y esa versión. La lista bloqueada la escribe el gestor. No se reescribe a mano.

No entra otro gestor ni otra lista de bloqueo.

Si la declaración del gestor no dice pnpm 12.15.0, el proyecto no está estandarizado.
