# El flujo de git de la app

El flujo de git del curso, entero, pasa a ser el flujo de trabajo de esta app. Pensar una tarea, dejarla escrita, empezar, guardar un trozo y pedir revisión se hacen por ese flujo.

Un desarrollo nuevo sigue parando después de la spec, después del plan y después de las tareas. Ese flujo no se salta esas paradas.

Pasar el trabajo a staging queda fuera de este flujo.

La aplicación sigue haciendo lo mismo con los usuarios. No se añade ningún paquete.
