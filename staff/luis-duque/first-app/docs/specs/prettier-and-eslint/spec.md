# Formato y revisión del código

El código se puede dejar con el formato de Prettier. Hay una forma de lanzar ese formato.

El código se puede revisar con ESLint. La revisión mira errores de código y de compilación. Hay una forma de lanzar esa revisión.

Al terminar una tarea, se tienen en cuenta Prettier y ESLint.

La aplicación sigue haciendo lo mismo con los usuarios.
