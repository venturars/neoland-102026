# Separar las guías

Las guías de la aplicación se reorganizan. Hay una guía de arquitectura, una del árbol, una de la base de datos, una de errores y una de estilo.

La constitución se queda con las specs, los paquetes y los cuatro pasos de la lógica. Enlaza a esas cinco guías.

La guía del agente se queda con el proceso SDD. Enlaza a la guía de estilo.

La aplicación sigue haciendo lo mismo. No se añade ningún paquete.
