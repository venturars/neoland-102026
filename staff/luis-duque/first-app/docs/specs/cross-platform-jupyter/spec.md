# Jupyter en Mac, Windows y Linux

Jupyter se puede lanzar en Mac, Windows y Linux.

Sigue habiendo una sola forma de lanzarlo desde la app. Esa forma llama a un script propio.

Al lanzarlo, se usa el entorno de la app y no el Jupyter del equipo. Si falta el entorno, se crea. Si falta Jupyter en ese entorno, se instala la misma versión de siempre. Se abre el cliente de Jupyter de la app en local.

Las operaciones de los usuarios siguen igual.
