# Align with the new constitution

## What

Reorganise the app so it follows the simpler constitution: same features, simpler code to read.

## Who

Junior developers reading and extending first-app.

## Input

Nothing.

## Output

The same features, with these visible changes:

- Messages: `Name is empty`, `Email is invalid`, `Email is already used`, `User not found`, and one `Could not …` message per feature when the database fails.
- Every user also shows when it was created and last updated.
- Each feature is tried by pasting its terminal block.

## Failures

None new.

## Out of scope

- New features.
- Automated tests (removed).
