# Get a user

## What

Show one user, chosen by their number.

## Who

Whoever manages the user list (an admin).

## Input

The user's number.

## Output

That user.
Example: 1 → user 1, `Ana`, `ana@x.com`, with its dates.

## Failures

- No user with that number → `User not found`.
- The user cannot be read → `Could not find the user`.

## Out of scope

- Searching by name.
