# Tasks

1. La vista People queda en el explorador de VS Code. No se instala ningún paquete.
2. `extension.js` llama a `listUsers`, `findUserById`, `createUser`, `updateUser` y `deleteUser`.
3. `index.html`, `panel.js` y `styles.css` crean, listan, ven, cambian y borran. `panel.js` solo manda mensajes.
4. `npm run vscode`, desde `first-app`, abre la ventana de desarrollo.
5. La constitución, la arquitectura, el árbol, `AGENTS.md` y `README.md` dicen cómo volver a abrirla.
6. Con `npm run db` en marcha, crear una persona temporal, verla, cambiar el nombre y borrarla. Un nombre vacío muestra `Name is empty`. Luego `npm run format` y `npm run lint`. Quitar a esa persona.
