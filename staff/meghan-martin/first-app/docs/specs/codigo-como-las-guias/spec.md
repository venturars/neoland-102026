# Spec — el código se lee como las guías

Quien lee una acción la sigue de arriba abajo. Cada comprobación tiene su propio `if`. Cada paso deja el resultado en un nombre. Lo que la acción devuelve, y lo que dice cuando falla, es lo de antes.

Entra lo mismo que ya entraba. Sale lo mismo que ya salía. Una persona guardada sigue siendo el mismo objeto. Un fallo sigue diciendo la misma frase.

Ejemplo: se guarda a Ada con el email en mayúsculas. Se guarda como Ada, con el email en minúsculas. Si ese email ya está, la frase es la de siempre.

Queda fuera una acción nueva, una frase de error nueva, y cambiar la base.
