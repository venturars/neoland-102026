# Tasks

1. Pasar las sentencias a `src/queries/users-sql.js` y quitar los `.sql`.
2. Abrir `src/db/server.js` para que solo ese fichero abra la base.
3. Hacer que `src/queries/users.js` pida cada sentencia por su nombre.
4. Hacer que `src/logic/` espere esas respuestas y conserve las frases de error.
5. Poner `await` en la terminal y en Jupyter, y cambiar la página a `index.html` y `app.js`.
6. Desde `first-app`, con una copia de la base, arrancar `npm run db`, probar una lista y parar el programa.
7. Lanzar `npm run format` y `npm run lint`.
