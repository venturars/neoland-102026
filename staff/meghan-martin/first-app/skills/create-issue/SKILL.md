# Crear la issue

Úsala solo para dejar la tarea escrita. No abras la rama ni la pull request.

El servidor es el de `MCPS/github-mcp-server/mcp.txt`.

1. Tipo: `feat`, `fix`, `docs`, `refactor`, `test` o `chore`. Si no es uno de esos, elige el más cercano y dilo. Ese mismo tipo vale para la rama y para la pull request. No renombres una rama que ya existe.
2. Título: inglés, empieza por un verbo, menos de 72 caracteres.
3. Cuerpo: español. Rellena `templates/issues/<tipo>_issue.md`.
4. Persona asignada: quien está autenticado.

Quédate con el número, el título y la URL. Si falla, dilo y no inventes el número.
