# Rama desde staging

Úsala cuando empieza el trabajo. El nombre es `número-tipo-descripcion`.

`staff/meghan-martin/first-app/tools/create-branch-from-staging.sh NUMERO TIPO DESCRIPCION`

1. `NUMERO`: el número de la issue, solo dígitos.
2. `TIPO`: `feat`, `fix`, `docs`, `refactor`, `test` o `chore`.
3. `DESCRIPCION`: inglés, minúsculas, con guiones.

Si la rama ya existe, el script se queda en ella. La rama nueva no sigue a `staging`. Si hay un merge a medias, para.
