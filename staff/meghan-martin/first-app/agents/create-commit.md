# Hacer el commit

Hay dos usos. No los mezcles.

- Al empezar: lee `skills/create-empty-commit/SKILL.md`. El mensaje es `chore: open #N`. No metas ficheros.
- Al guardar un trozo: lee `skills/commit-changes/SKILL.md`. Solo los ficheros nombrados.

No hagas commit en `main` ni en `staging`. No uses stash, `reset --hard` ni `clean`. Si un hook de git de verdad podría cambiar el commit, para.

Responde con el mensaje y la rama.
