# Abrir la rama

La rama sale de `staging`. El nombre es `número-tipo-descripcion`.

El tipo es el mismo que el de la issue: `feat`, `fix`, `docs`, `refactor`, `test` o `chore`. Si llega otro, elige el más cercano, dilo, y usa ese en el nombre. No cambies una rama que ya existe. No pases al script un tipo distinto de esos seis.

Lee `skills/create-branch-from-staging/SKILL.md`. No hagas el commit ni la pull request.

Si la rama ya existe, quédate en ella. Responde con el nombre.
